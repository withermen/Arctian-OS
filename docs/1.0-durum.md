# 1.0 durum defteri

Bu belge 1.0'a giden yolda hat bazında neyin bittiğini ve neyin henüz test
edilmediğini kısa ve dürüst biçimde toplar. Ayrıntılı iş listesi:
[1.0-yol-haritasi.md](1.0-yol-haritasi.md).

Son güncelleme: 0.9.1 sonrası 1.0 hazırlık turu.

## Özet

| Hat | Kapsam | Durum |
|---|---|---|
| A | Açılış / ilk izlenim | Selftest'ler üretimden çıktı, animasyon kısaldı, giris.md iki ekran login |
| B | Güvenlik | Kritik 10 madde kodla doğrulandı (TCP/UDP/DNS/wlf/syscall/fd/TLS) |
| C1 | .wlf ring 3 izolasyonu | ✅ B1/B2 tamam |
| C3 | `wolf_api` köprüsü (B3) | ⏳ en büyük açık iş |
| D | Stabilite | `-smp 4` sync takılması açık |
| E | Yayın | QuickJS/wolf_engine kaldırıldı; 0.9.1 ISO/IMG + release akışı hazır |

## A — Açılış

**Bitenler**

- Çekirdek öz-testleri (`sched`, `proc`, `caps`, `afs`, `lab`) artık normal
  açılışta koşmuyor; `make pack SELFTEST=1` ile açılıyor. Ölçülen kazanç
  ~1.5 sn ve B1 örneğindeki zamanlayıcı bozulma riski ortadan kalktı.
- B1 ring 3 selftesti ayrı bayrağa alındı (`WFL_SELFTEST=1`).
- Açılış animasyonu sabit beklemesi 4300 → 350 ms.
- Login ekranları `giris.md` şartnamesine göre yeniden yazıldı: hesap
  oluşturma (kapsül + Evet/Hayır) ve kullanıcı seçme (gradyan avatarlar,
  seçim halkası, şifre kapsulu). 1280×720 referans tuval, eşit oranlı
  ölçek + ortalama; Manrope 200/600/700 (SIL OFL, gerçek TTF).
  QEMU'da iki ekran + parola oluşturma + parola ile giriş doğrulandı.
- `asi->console` köprüsü dolduruldu; masaüstü ve uygulamalar artık seri
  hatta tanılama basabiliyor (önce hiçbir satır üretemiyordu).

**Ölçüm (QEMU/TCG, -smp 1, 1024M)**

| Sürüm | Toplam |
|---|---|
| 0.9.1 öncesi | 8.78 sn |
| Öz-testler çıkarıldı | 6.38 sn |
| Animasyon 350 ms | ~6.3 sn |

**Açık**

- Desktop modülünün ISO'dan okunması ~3.5 sn (11 MB). Sıkıştırma veya
  modül önbelleği düşünülebilir.
- Odak halkası ilk açılışta metin alanı yerine bir düğmede görünüyor;
  grup odağı cilalaması açık (işlevsel akış etkilenmiyor).

## B — Güvenlik

Kod okuyarak doğrulanan (hepsi kapalı): TCP `conn_id` sınırı, TCP alıcı
penceresi, `.wlf` fail-closed yetki, syscall sayfa-sayfa tampon denetimi,
süreç başına fd tablosu + okuma ofseti, UDP 1400 bayt sınırı, DNS sıkıştırma
sıçrama limiti, mbedTLS `realloc` kopyalama, `SYS_GETPID`/`SYS_TICKS`
köprüleri.

## C — .wlf izolasyonu

B1 (ring 3 + ayrı CR3 + W^X + exit kancası) ve B2 (masaüstü bağlantısı)
tamam. **B3 açık:** `wolf_api_t` trampoline tablosu, `SYS_WOLF_*` dağıtıcısı,
UI broker ↔ LVGL köprüsü yok. GUI'li native `.wlf` uygulamaları bu yüzden
çalışmıyor; CLI/native izole yol ve script (VM) uygulamaları çalışıyor.

## D — Stabilite

- `auth.c` salt üretimi RDRAND'ı koşulsuz çalıştırıyordu; RDRAND olmayan
  CPU'larda (qemu64) hesap oluşturma #UD panic veriyordu. CPUID kapısı
  eklendi; fallback karışım zaten vardı. QEMU'da EXC=0 doğrulandı.
- Saat kaynakları tutarsız: terminal `date` civil tarihi ile unix değeri
  farklı gün gösteriyor; login gün adı bir gün kayıyor. Kök neden
  `clock.c` / `ntp.c` / RTC etkileşimi; 1.0'da kök neden + düzeltme.
- `-smp 4`'te sync selftest takılması C4 döneminden beri açık;
  `-smp 1` ISO temiz.
- Serial konsol kilidi yok (SMP logları karışabilir).

## Genel sınırlar

- Canlı (RAM) masaüstü yok; ISO kurulum akışına gider.
- Ağ sürücüleri kısmi (e1000, PCnet, RTL8139/8169; virtio-net yok);
  Wi-Fi ath9k + iskelet AX201.
- UEFI önyükleyici iskelet: OVMF'de GOP + ESP okuma var, çekirdek atlama yok
  (BIOS/MBR yolu kullanılıyor).
- Ayrıntılı hata listesi: [bilinen-hatalar.md](bilinen-hatalar.md).
