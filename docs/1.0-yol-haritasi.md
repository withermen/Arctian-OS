# 1.0 yol haritası — durum defteri

Bu dosya 0.9.1'den 1.0'a giden işleri izler. Her madde **kanıtla** kapanır
(derleme + QEMU testi veya kod incelemesi). Kanıtsız madde "yapıldı" sayılmaz.

Son güncelleme: 0.9.1 sonrası, 1.0 hazırlık turu.

## B. Güvenlik (1.0 için zorunlu)

`docs/bilinen-hatalar.md` 76 maddenin tamamı "düzeltildi" diyor; kod
doğrulaması yapılanlar aşağıda. Kalanlar için tek tek kod kanıtı gerekiyor.

| # | İş | Durum |
|---|---|---|
| B1 | TCP `conn_id` sınır denetimi | ✅ `tcp_id_ok(conn_id)` sınır kontrolü + state denetimi |
| B2 | TCP alıcı penceresi / yeniden gönderim | ✅ `peer_window` + `send_buffer` var |
| B3 | `.wlf` `flags==0` → CAP_ALL fail-open | ✅ fail-closed: `p = 0` → `CAP_FS` (en gerilemeli) |
| B4 | syscall `user_range` sayfa haritalı mı | ✅ `user_range_w`: her 4K sayfa U-biti + haritalı kontrolü |
| B5 | fd tablosu süreç başına | ✅ `g_fds[FD_PROCS][FD_SLOTS]`, pid'e göre |
| B6 | `SYS_READ` dosya ofseti | ✅ `g_fd_off[][]` (EOF görülür) |
| B7 | UDP 1500 bayt sınırı | ✅ `data_len > 1400` → fail |
| B8 | DNS sıkıştırma döngü koruması | ✅ `jumps > 8` → bozuk cevap |
| B9 | mbedTLS `realloc` içerik kopyalama | ✅ `kmalloc`+`memcpy`+`kfree` |
| B10 | `SYS_GETPID`/`SYS_TICKS` gerçek değer | ✅ `s_pid_fn` / `s_ticks_fn` köprüleri |

> **Güvenlik özeti:** 0.9 belgelerinde "düzeltildi" denen 76 maddenin
> 1.0 için kritik gördüğüm 10 tanesini kod okuyarak doğruladım; hepsi
> gerçekten kapalı. Kalanlar için tek tek kod kanıtı hâlâ gerekli (bkz.
> `docs/bilinen-hatalar.md`).
